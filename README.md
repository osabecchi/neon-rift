# NEON RIFT(ネオン・リフト)

ネオンの裂け目で戦う、ツインスティック型のローグライト・シューター。
敵を倒して経験値を集め、レベルアップのたびに3枚のカードから強化を選んで機体を育てる。全10ウェーブを戦い抜き、最終ボスを倒すとクリア。

## 遊び方

`index.html` をブラウザー(Chrome / Edge / Firefox / Safari の最新版)で開くと遊べます。ビルドやインストールは不要です。フォント以外は外部に依存しません(オフラインでも代替フォントで動きます)。

| 操作 | キーボード・マウス | ゲームパッド |
| --- | --- | --- |
| 移動 | WASD / 矢印キー | 左スティック |
| 照準 | マウス | 右スティック(離すと自動照準) |
| 射撃 | 自動(設定でクリック中のみに変更可) | 右スティック / RT |
| ダッシュ(無敵) | Space / Shift / 右クリック | A / RB |
| オーバードライブ | E / Q / ホイールクリック | X / Y / LB |
| ポーズ | Esc / P | START |
| カード選択 | 1〜4 / 矢印+Enter / クリック | 十字キー + A |

スマホでは画面左のドラッグで移動、右のドラッグで照準。DASH / OD ボタンの外周がゲージになっています。

## スマホのホーム画面にアプリとして追加する

ホーム画面に追加できる形(PWA)になっています。追加すると専用アイコンから全画面で起動し、一度開いたあとはオフラインでも遊べます。

1. このフォルダ(`neon-rift`)をインターネット上に公開する。GitHub は必須ではありません。
   - **Netlify Drop**(GitHub 不要): パソコンのブラウザーで https://app.netlify.com/drop を開き、`neon-rift` フォルダをドラッグ&ドロップする。無料アカウントを作るとずっと残る。
   - **GitHub Pages**: リポジトリにこのフォルダの中身を置き、Pages を有効にする。
2. スマホで公開された URL を開く。
   - iPhone: Safari の共有ボタン →「ホーム画面に追加」
   - Android: Chrome のメニュー →「アプリをインストール」または「ホーム画面に追加」

ファイルを直接ダブルクリックして開いた場合や claude.ai の公開ページでは、ホーム画面のアプリにはなりません(遊ぶことはできます)。

## システム

- **レベルアップと構築**: メイン武装の改造7種・サブ武装10種・パッシブ12種・レジェンダリー8種から選ぶ。サブ武装は4枠、パッシブは5枠、レジェンダリーは3つまで。
- **進化**: サブ武装をLv5にして対応するパッシブを持つと、進化カードが出る(10種類)。宝箱からも出る。
- **ジャスト回避**: 敵弾やレーザーに当たる瞬間にダッシュするとスローになり、ドライブが大きく溜まる。
- **グレイズとオーバードライブ**: 敵弾をかすめるとゲージが溜まる。発動中は火力1.5倍・連射アップ・敵が減速・スコア2倍。
- **コンボ**: 撃破を続けるとスコア倍率が最大×8。被弾でリセット。
- **敵**: 13種類の雑魚と精鋭(金色・宝箱を落とす)、4体のボス(イージス・コア / リヴァイアサン / ハイヴ・クイーン / ヌル・シンギュラリティ)。
- **モード**: キャンペーン(10ウェーブ。5ウェーブ目は3体からランダムな中ボス、10ウェーブ目は最終ボスのヌル・シンギュラリティ)・エンドレス(無限。5ウェーブごとに4体のボスが順番に出る)・デイリー(日替わりの機体と特殊ルールで10ウェーブ)。クリア後はエンドレスへ続行できる。
- **ラボ**: 出撃で得たコアで永久強化12種、機体3機、武装4種を解放。
- **RISK**: キャンペーンをクリアするたびに難易度を1段階上げられる(最大10)。スコアとコアが増える。
- **記録と実績**: 実績24種(達成でコア獲得)。データはブラウザーに保存されます。

## 技術メモ

- 描画は自前の WebGL2 レンダラー(インスタンス描画・HDRレンダーターゲット・多段ブルーム・衝撃波の歪み・色収差)。スプライトは起動時に Canvas2D で描いてアトラス化。
- 背景のグリッドはばねで繋がった格子で、爆発やブラックホールで波打つ。
- 効果音と BGM はすべて WebAudio でその場で合成(曲は強度に応じて楽器が増える)。
- 画質「自動」は処理落ちを検知すると描画解像度→画質プリセットの順に下げる。
- 敵の当たり判定は空間ハッシュ、弾・パーティクルはプールで使い回し、毎フレームのメモリ確保を抑えている。

## ファイル構成

```
index.html      起動ページ
manifest.webmanifest  ホーム画面に追加したときの名前・アイコン・全画面表示の設定
sw.js           オフラインで起動するためのサービスワーカー
icons/          アプリアイコン(512 / 192 / 180px)
css/style.css   UI
js/core.js      数学・乱数・プール・空間ハッシュ
js/data.js      機体・強化・敵・ウェーブ・ラボ・実績のデータ
js/save.js      セーブデータ
js/audio.js     効果音とBGMの合成
js/input.js     キーボード・マウス・タッチ・ゲームパッド
js/sprites.js   スプライトアトラスの生成
js/gfx.js       WebGL2 レンダラーと後処理
js/icons.js     強化アイコン
js/fx.js        パーティクル・グリッド・星空
js/weapons.js   武装と投射物
js/enemies.js   雑魚敵の行動
js/bosses.js    ボスの行動と弾幕
js/game.js      ゲーム本体
js/ui.js        画面とHUD
js/main.js      起動とメインループ
```
